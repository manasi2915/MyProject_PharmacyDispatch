# 04 — SRS and Work Breakdown Structure

**Project:** Pharmacy Expiry & Re-order Dispatch Engine (Problem Statement #15)

| File | Description |
|------|-------------|
| `SRS.docx` | Software Requirements Specification: introduction, overall description, specific requirements (FR/NFR), use-case model with the UC-02 flow, architecture summary, and traceability |
| `WBS.docx` | Work Breakdown Structure: a WBS tree of 6 phases and 22 work packages, plus a work package dictionary (output, linked requirement, dependencies) |

## WBS Phases

1. **Requirements:** elicitation, FR/NFR specification, use-case modelling, RTM
2. **Design:** architecture, database schema, UI wireframes, SRS
3. **Implementation:** batch registration, FEFO engine and dispensing, scheduler and stock monitor, PO generation and dispatch, supplier portal, audit logging
4. **Testing:** unit, integration, performance and security (NFR-001), user acceptance
5. **Deployment:** environment setup, go-live
6. **Project Management:** Jira sprint planning, GitHub version control (runs alongside all phases)
